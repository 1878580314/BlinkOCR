BlinkOCR Windows 便携版

1. 双击 BlinkOCR.exe。
2. 在“模型库”下载并加载模型，或使用“本地加载”选择文件。
3. 模型就绪后按 End，或点击“框选识别”。
4. 识别结果可以直接编辑，点击“复制全文”或按 Ctrl+Shift+C 复制。

窗口会依据显示器工作区与系统缩放调整为合适的正方形尺寸。
快捷键在“设置 → 体验”中点击按键框，直接按键录入。
Esc 取消录入或当前框选；关闭窗口会收起到托盘。
从托盘菜单、体验设置或默认 Ctrl+Alt+Q 退出应用。

“Xiaomi 表格增强”位于“设置 → 识别”，默认关闭。
它只用于 Xiaomi-OCR 的通用识别，最多增加三次补充请求。
补充内容和差异候选在独立区域展示。

视觉语言模型使用 GGUF，除 TeleOCR 外需要配套视觉投影。
PP-OCRv6 使用检测和识别两个 ONNX 文件，字典按规格自动匹配。
Windows.Media.Ocr 直接使用系统组件，识别语言在模型设置中选择。
模型可放入 models/，也可以在设置中选择其他位置的文件。
bin/ 与 DirectML.dll 是随程序提供的推理组件。
设置保存于 config.rust.toml。
Windows 需要 Microsoft Edge WebView2 和 Microsoft Visual C++ v14 x64 运行时。

连续识别：开启主界面的“连续识别”后，每次框选或选择图片的结果会追加到当前内容。
识别前的手动编辑会保留；点击“新建”清空当前结果并重新开始。

将鼠标悬停在设置项上，或用键盘聚焦控件，可查看作用与调整建议；Esc 收起说明。

模式随模型切换。非 Xiaomi 模型会强制关闭表格增强。
CPU 线程默认使用逻辑核心数的一半，硬件信息显示 CPU 型号。
均衡图像设置使用模型默认 token 数；常规模型长边 2048，Windows OCR 长边 4000。
版本号在程序顶部显示，设置页使用悬浮的保存与取消按钮。
